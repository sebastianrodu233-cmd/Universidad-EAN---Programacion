# Universidad EAN - Programación

Repositorio correspondiente a los proyectos desarrollados para la asignatura de Programación de la Universidad EAN.

## Actividades

### Actividad 1 - Diagramas UML

Se desarrollaron diagramas de clases UML para representar la estructura de los proyectos:

- Feria Empresarial
- Gestión de Parqueadero

Los diagramas muestran las clases, atributos, métodos y relaciones entre los diferentes elementos del sistema.

### Actividad 2 - Feria Empresarial

Aplicación desarrollada en Java para simular la gestión de una feria empresarial.

El sistema permite gestionar:

- Empresas.
- Stands.
- Visitantes.
- Comentarios y calificaciones.
- Reportes.

Proyecto ubicado en:

`Actividad-2-FeriaEmpresarial`

### Actividad 3 - Gestión de Parqueadero

Aplicación desarrollada en Java para gestionar un parqueadero utilizando conceptos de programación orientada a objetos.

El sistema permite:

- Registrar la entrada de vehículos.
- Registrar la salida de vehículos.
- Consultar el estado del parqueadero.
- Calcular el costo de parqueo.
- Gestionar automóviles, motocicletas y camiones.

El proyecto implementa:

- Herencia.
- Polimorfismo.
- Encapsulamiento.

Proyecto ubicado en:

`Actividad-3-GestionParqueadero`

## Tecnologías utilizadas

- Java
- Apache NetBeans
- GitHub

## Ejecución

Los proyectos pueden abrirse individualmente en Apache NetBeans.

Para ejecutar cada aplicación:

1. Abrir el proyecto correspondiente.
2. Ubicar la clase `Main.java`.
3. Ejecutar `Main.java`.
4. Seguir las instrucciones mostradas en la consola.
